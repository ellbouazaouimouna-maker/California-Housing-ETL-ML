# California Housing — ETL & Machine Learning Pipeline

## Project Overview
An end-to-end Data Engineering and Machine Learning project designed to process California housing data and predict median house values.

## Objectives
- Build a Python ETL pipeline for data extraction, cleaning and transformation.
- Store data in PostgreSQL using staging tables and a star-schema Data Warehouse.
- Train and evaluate regression models for housing price prediction.
- Create interactive Power BI dashboards.

## Tech Stack
- Python, pandas, NumPy
- PostgreSQL, SQLAlchemy
- scikit-learn
- Power BI
- Git and GitHub

## Dataset
California Housing Prices (Kaggle):
https://www.kaggle.com/datasets/camnugent/california-housing-prices
